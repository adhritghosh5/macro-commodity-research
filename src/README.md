# Python Analytical Library (`src/`)

This directory contains modular Python utilities supporting data ingestion, financial indicator engineering, quantitative signal calculation, and high-resolution visual charting.

## Modules

* **[`data_loader.py`](file:///c:/Users/adhri/Downloads/Research%20Portfolio/macro-commodity-research/src/data_loader.py):** Standardized ingestion classes for market time-series, corporate fundamentals, and macro series.
* **[`indicators.py`](file:///c:/Users/adhri/Downloads/Research%20Portfolio/macro-commodity-research/src/indicators.py):** Mathematical definitions for rolling Z-scores, base-reindexing, and 3:2:1 crack spread proxies.
* **[`signal_engine.py`](file:///c:/Users/adhri/Downloads/Research%20Portfolio/macro-commodity-research/src/signal_engine.py):** Implements the 5-layer commodity scarcity signal ($S_t$) with dynamic weighting and regime classification.
* **[`visualizer.py`](file:///c:/Users/adhri/Downloads/Research%20Portfolio/macro-commodity-research/src/visualizer.py):** Matplotlib/Seaborn institutional styling and chart generation pipelines.
